Last spring snow (day of year) Linear trend (observed) Projection: model median + range, 11-yr smoothed
Observed: ERA5 reanalysis (Hersbach et al., 2020; ~25 km grid cell containing 47.62°N, 117.53°W) via the Open-Meteo Historical API. ERA5 is a model-based reconstruction, not a station snow gauge. Projections: CMIP6 high-resolution models (HiRAM-SIT-HR, MRI-AGCM3-2-S, EC-Earth3P-HR, MPI-ESM1-2-XR, NICAM16-8S), a high-emissions scenario described by the provider as "as close to RCP8.5 as possible", via the Open-Meteo Climate API (CC BY 4.0). Each model is shifted so its 1950–2024 mean matches ERA5's; only the change over time comes from the model. A day counts as snowy when its snowfall meets the selected minimum. Results depend strongly on that choice. Spring = Jan 1–Jun 30; fall = Jul 1–Dec 31. Seasons still in progress are left out. Source on GitHub · projectinsomnia.com
